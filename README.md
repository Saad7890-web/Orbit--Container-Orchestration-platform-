# Orbit

Orbit is a lightweight container orchestration and automation daemon for single-node and edge environments.

## Goals

- Run long-lived container services
- Run scheduled jobs
- Trigger containers from events
- Use Docker Engine as the runtime
- Keep the system lightweight and production-friendly

## Binaries

- `orbit`
- `orbitd`

## Version

```bash
orbit --version
orbitd --version
```
